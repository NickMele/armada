## What the line found that nothing else had

- **Two `config` tests had been failing on `main` since 2158736a**, invisible
  because agents run their own crate's tests rather than the Manifest's Checks.
- **`cargo-nextest` was not installed on this machine**, so `test` and
  `acceptance` had never been able to pass here, for the line or for a Job.
- **Gate worktrees outside the repository break the front-end tooling** — Vite
  refuses to serve `node_modules` from `.git/`, and `tsc` resolves types
  differently. Fleet's `.armada/worktrees/` convention exists for this reason.
