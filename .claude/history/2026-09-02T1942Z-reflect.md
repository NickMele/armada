This session touched no Rust. The failure was found only because the skill

session's, and cost the evening.

the Drone was silent, the vigil poked it correctly, and the test failed saying

never established, which is why it read as a Fleet bug rather than a test bug
for as long as nobody looked.

`armada/test-flakiness-under-load` had diagnosed the same class in two other
lines on 17 August, with measurements, and was never filed as an issue. A plan
commit on an unmerged branch is not a durable home.

## What a play is for, written down

standard for a rendered assertion and the document never said it. The citation
resolved to nothing, so an agent following it learned nothing.

Two things cost time here and neither is guessable. A pointer left resting on a
chip keeps a hover-opened card open, so an assertion that the layer closed
passes against a component that has stopped pinning entirely. And an element
with no role has to be found through the structure, because its class is what a
refactor moves.

`JobDiffSheet`'s rail carried the open file in `data-on` and the stylesheet
alone. Asserting that would have been a test of the stylesheet wearing a test's
clothes, so the row took `aria-current` — which `StepRow` already used for the
same fact.
