## What this session learned

**A branch that waits loses a protocol minor every few hours.** #1187 was renumbered
three times, each costing a merge, a doc edit and a full test run. The owner's answer
was to merge on green rather than hold for review, and that ended it. Where a branch
carries a wire change, the version is a claim about a moment and is stale the moment
it is written.

**A fixture nothing draws is a feature nobody can see.** After #1185 and #1187 merged,
the mock's running Job still showed no task rows, because the only plan fixture with
working windows was read by tests alone. The owner read the merged work as not landed.
A mock scenario is what a person checks the work against, so a change to a screen owes
one.

**A fixture dated last week makes every instrument read empty.** The mock reads the
real clock, so the Activity instrument drew twenty-four empty windows and the header
read 173 hours — a Job asleep on the screen built to say it is not.

**Storybook runs a story's play on open**, so a one-way control in a story has already
been pressed by the time anyone looks at it. That read as a broken button.
