# Should the way he decides be written down?

**Decided 2026-09-23.**

Every decision in a session lived in issue bodies and a conversation, so the next session started from nothing.

**Chosen:** Both: a record of each decision as it is made, and a skill distilled from it.

**Cost he took:** The skill is only as good as the decisions in it, and it will read as more certain than it is.

**Where it landed:** this file, and .claude/skills/how-the-owner-decides/
