# Does an Epic's wave draw the landing band?

**Decided 2026-09-22.**

Both regions read the same wire field, so a wave drew 'parked until the one before it lands' about a Job that had merged.

**Chosen:** A wave is a dependency graph and not a landing order. No moment carries both.

**Cost he took:** Bridge draws a wave only where something says a Job is one, rather than deriving it.
