# packages/

Shared TypeScript that more than one app needs — the generated IPC types, and
whatever else Bridge and a future surface both read. A package created before
it has a second consumer is a folder with an import path, so nothing lands here
until something is actually shared.

- `tokens/` — the design tokens. Authored in `src/*.css`, which is the
  authority on every design value in Armada; everything else it holds is
  generated by `cargo xtask verify-tokens`. See its README.
