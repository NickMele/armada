# Instruction sets

The two surfaces that are not this repository each carry their own instructions,
and both are pasted in by hand — neither platform reads a file from here. The
canonical text lives in this directory so it can be diffed, and so the three
sets say the same thing about where a fact lives rather than three
approximations of it.

| File | Pasted into |
|---|---|
| `claude-desktop.md` | The Armada project's instructions in the Claude desktop app |
| `claude-design.md` | `CLAUDE.md` in the Armada Mockups design project |

**Each file is exactly what gets pasted, byte for byte.** No header, no note
about being canonical — anything in the file would go into the destination
along with it. That is what this README is for.

**Edit here first, then paste.** A change made only in the app is a change the
next person cannot find.

## What both must agree on

| Holds | Home |
|---|---|
| Contracts, practices, concepts, journeys, spikes, open questions | The repository |
| Registries code reads — tokens, icons, settings, the domain model | The repository |
| What is being built and in what order | GitHub issues and milestones |
| Mockups, the component sheet, the canvas | The design project |

**The design workspace is no longer a working surface**, and nothing sits
between the repository and the design project.
