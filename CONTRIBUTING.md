# Contributing

**Not yet, and thank you for looking.**

Armada is one person's project and its foundations are still moving. A change
made against them today would be built on something that changes next week,
which wastes your time rather than mine.

## What is useful now

- **Issues and questions.** If something here is interesting or wrong, say so.
- **Telling me a rule does not hold.** The repository claims a set of
  constraints in `ARCHITECTURE.md` and `SECURITY.md`. A case where one fails is
  the most useful thing you could send.

## What to expect if you open a pull request

It will be read, and probably not merged — not because it is bad, but because
there is nothing stable to merge it into. This file will change when that
changes.

## If you are here to build on it

The licence is [Apache 2.0](LICENSE). Fork it. `ARCHITECTURE.md` is the map and
`cargo xtask verify-foundations` will tell you what is not finished, loudly.
